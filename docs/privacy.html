Privacy Policy

Last updated: 9 August 2026

Balavie is a free and open-source meal and macro tracker providing approximate nutrition information for educational purposes.
Privacy summary
  • Balavie does not sell personal information.
  • Balavie does not contain advertising trackers.
  • Users provide and manage their own Gemini API key.
  • Meal information is sent to Gemini only upon user request.
  • Saved meal photographs are private by default.
  • Users can delete meals, photographs, and their account.
  • Balavie is intended only for users aged 18 and over.

1. About Balavie

Balavie helps users record meals, review estimated calories and nutrients, and receive AI-assisted nutrition and lifestyle estimates.

3. Age requirement

Balavie is intended only for users aged 18 and over. Users must provide a one-time confirmation that they are at least 18 years old.

Balavie may store the confirmation status, date, and policy version. Balavie does not require or retain a complete date of birth for this purpose.

4. Information processed

Account information

Firebase Authentication may process:

  • User identifier
  • Email address
  • Display name
  • Profile photograph URL, where provided
  • Authentication and account-security information

Meal information

Balavie may process:

  • Meal descriptions, dates, and times
  • Meal photographs
  • Estimated calories and nutrients
  • Balance Scores
  • AI-generated nutrition and lifestyle estimates

Profile settings

Balavie may process:

  • Body weight
  • Dietary preferences
  • Activity level
  • Nutrition targets
  • Theme and interface preferences

Consent records

Balavie may retain:

  • 18+ confirmation status, date, and version
  • Gemini consent status, date, and version
  • User-supplied API key acknowledgement

5. Gemini meal analysis

Balavie uses Google’s Gemini API to generate approximate meal and nutrition estimates.

Balavie operates in Bring Your Own Key mode. Users must supply, fund, protect, and manage their own Gemini API key.

When analysis is requested, Balavie may send Gemini:

  • The meal description
  • The selected meal photograph
  • Relevant dietary and activity settings
  • Relevant nutrition targets

Information is sent only after the user confirms being 18 or over, accepts the Gemini processing notice, provides a personal API key, and explicitly requests meal analysis.

Google controls Gemini API pricing, quotas, billing, availability, data practices, and service terms. Balavie cannot verify whether a user’s Gemini project is configured for a free or paid service tier.

6. Gemini API keys

A Gemini API key may be stored locally in the user’s browser or installed PWA. Gemini keys are not synchronized to Firebase or Firestore.

The key is transmitted to the Balavie backend only when required for a user-requested Gemini operation.

Users can remove a saved Gemini API key through Balavie Settings.

7. Meal photographs

Meal photographs may be used for Gemini analysis and saved privately with the user’s meal history.

Cloud photographs are stored in Firebase Storage. Firestore stores only the required photograph reference and metadata rather than Base64 image data.

Photographs are private by default and are not automatically published or shared.

Cloud meal photographs are retained for up to six months unless the user deletes the photograph, meal, or account earlier.

8. Local storage

Balavie may store the following information on the user’s device:

  • Meal history and locally retained photographs
  • Dietary, activity, and interface settings
  • Analysis counters
  • Gemini API key
  • Age-confirmation and consent records
  • Firebase Authentication state

9. Cloud synchronization

Signed-in users may synchronize meal descriptions, nutrition estimates, Balance Scores, recommendations, dates, and private photograph references using Firebase Firestore.

Gemini API keys are not synchronized.

10. Device permissions

Camera or photo-library access is requested only when the user chooses to take or select a meal photograph.

Balavie does not require location, contacts, SMS, call-log, or microphone access for meal analysis.

11. Optional donations

Balavie may offer optional donations processed by Stripe. Donations do not unlock premium features, subscriptions, additional analyses, higher limits, or extra storage.

Balavie does not send meal data, photographs, nutrition results, dietary settings, Firebase history, or Gemini API keys to Stripe.

Balavie does not store complete payment-card information. Gemini API charges are separate and are paid directly by the user to Google.

12. Service providers

  • Google Gemini API for meal analysis
  • Google Cloud Run for application hosting
  • Firebase Authentication for accounts
  • Firebase Firestore for synchronized meal records
  • Firebase Storage for private meal photographs
  • Stripe for optional donations
  • GitHub and GitHub Pages for source code and policy pages

13. Advertising and sale of information

Balavie does not sell or rent personal information and does not use meal information, photographs, dietary settings, or API keys for advertising.

14. Technical logs

Hosting providers may generate technical logs concerning requests, runtime errors, security events, and application performance.

Balavie does not intentionally log Gemini API keys, complete meal photographs, or Base64 image content.

15. Data retention

  • Meal records remain until deleted by the user.
  • Cloud photographs are retained for up to six months.
  • Account information remains until account deletion.
  • Local information remains until removed from the device.
  • Stripe may retain donation records according to its obligations.
  • Technical logs may remain temporarily in provider systems.

16. Data deletion

Users may delete individual meals and photographs from Balavie.

Signed-in users may use Delete Account & Cloud Data to request deletion of their Firebase account, synchronized records, stored photographs, local information, API key, and consent records.

./data-deletion.html Read the Account and Data Deletion instructions

17. Security

Balavie uses HTTPS, Firebase Authentication, and Firebase security rules. No online service can guarantee absolute security.

Users are responsible for protecting their device, Google account, Balavie session, and Gemini API key.

18. Health information

Balavie provides approximate nutrition information for educational purposes only. Results may be inaccurate and are not medical advice, diagnosis, or treatment.
