Privacy Policy

Last updated: 9 August 2026

Balavie is a free and open-source meal and macro tracker. Balavie provides approximate nutrition and lifestyle information for educational purposes only.
Privacy summary
  • Balavie does not sell personal information.
  • Balavie does not contain advertising or advertising trackers.
  • Users provide and manage their own Gemini API key.
  • Meal information is sent to Gemini only when a user explicitly requests analysis.
  • Saved meal photographs are private by default.
  • Users can delete individual meals, photographs, or their complete Balavie account.
  • Balavie is intended only for users aged 18 and over.

1. About Balavie

Balavie is maintained as a free and open-source learning project. Balavie helps users record meals, review estimated calories and nutrients, and receive AI-assisted nutrition and lifestyle estimates.

The Balavie application is available at:

https://balavie.ai.studio/

The source code is available at:

https://github.com/himanshumakhija9/Balavie

3. Age requirement

Balavie is intended only for users aged 18 and over. During onboarding, users are required to confirm that they are at least 18 years old.

Balavie does not require the user’s complete date of birth for this purpose. Balavie may store the age-confirmation status, confirmation date, and applicable age-policy version.

The age-confirmation record is not used for advertising, nutrition recommendations, Gemini prompts, optional donations, or commercial profiling.

4. Information Balavie processes

Account information

When a user signs in, Firebase Authentication may process:

  • A Firebase user identifier
  • Email address
  • Display name
  • Profile photograph URL, when provided by the sign-in provider
  • Authentication and account-security information

Meal information

Balavie may process information entered, uploaded, or generated when a user records a meal, including:

  • Meal descriptions
  • Meal dates and times
  • Meal photographs
  • Estimated calories
  • Estimated protein, carbohydrates, fat, fibre, and micronutrients
  • Balance Scores
  • AI-generated nutrition and lifestyle estimates

Profile and dietary settings

Balavie may process settings used to calculate or personalize general nutrition estimates, including:

  • Body weight
  • Diet type or dietary preference
  • Activity level
  • Nutrition targets
  • Theme and interface preferences

Eligibility and consent records

Balavie may retain limited records showing:

  • Confirmation that the user is aged 18 or over
  • Date and version of the age confirmation
  • Gemini data-processing consent status
  • Date and version of the Gemini consent
  • Acknowledgement of the user-supplied API key conditions

5. Gemini meal analysis

Balavie uses Google’s Gemini API to produce approximate meal and nutrition estimates.

Balavie operates in Bring Your Own Key mode. Balavie does not provide or pay for a shared Gemini API key. Users must create, provide, fund, and manage their own Gemini API key.

When the user explicitly requests meal analysis, Balavie may send the following information to the Balavie backend and Google’s Gemini API:

  • The meal description entered by the user
  • The selected meal photograph, where provided
  • Relevant dietary settings
  • Relevant activity or nutrition-target settings

Balavie sends this information only after the user has:

  • Confirmed being aged 18 or over
  • Accepted the one-time Gemini data-processing notice
  • Provided a personal Gemini API key
  • Explicitly requested meal analysis

Google processes information according to the terms and privacy conditions applicable to the user’s Gemini API project. Google controls Gemini API pricing, quotas, billing, availability, and service terms.

Balavie cannot independently confirm whether a user’s Gemini project is configured for a free or paid service tier. Users are responsible for reviewing Google’s current documentation and configuring their Gemini API project appropriately.

6. Gemini API keys

A Gemini API key entered in Balavie may be stored in the user’s browser or installed PWA on the user’s device.

Gemini API keys are not synchronized to Firebase or Firestore and are not intentionally retained in Balavie’s cloud database.

The API key is transmitted securely to the Balavie backend only when required for a user-requested Gemini operation.

Users should treat Gemini API keys as confidential credentials. A user can remove a saved API key through Balavie Settings.

7. Meal photographs

Meal photographs may be used for user-requested Gemini analysis and saved privately with the user’s meal history.

Cloud meal photographs are stored separately using Firebase Storage. Firestore stores only the required photograph reference and related metadata. Original photographs are not stored as Base64 data inside Firestore meal documents.

Saved photographs are private by default. Balavie does not automatically publish, share, or post meal photographs to social-media services.

Saved cloud meal photographs are retained for up to six months from their upload date unless the user deletes the photograph, associated meal, or complete Balavie account earlier.

At the end of the photograph-retention period, the photograph is removed from cloud storage and its storage reference is removed. The remaining meal-history record may continue to exist until the user deletes it.

8. Local device storage

Balavie may use browser localStorage, sessionStorage, IndexedDB, and PWA storage to maintain:

  • Local meal history
  • Locally retained meal photographs
  • Dietary and activity settings
  • Theme and interface preferences
  • Analysis counters
  • A Gemini API key entered by the user
  • Age-confirmation and Gemini-consent records
  • Firebase Authentication state

Locally stored information remains on the device until removed through Balavie, browser settings, application removal, or account deletion.

9. Cloud synchronization

Signed-in users may synchronize meal records using Firebase Firestore. Synchronized records may include:

  • Meal descriptions
  • Meal dates and times
  • Estimated nutrition values
  • Balance Scores
  • Generated recommendations
  • Private photograph references
  • Synchronization identifiers

Gemini API keys are not included in synchronized meal records.

10. Camera and photo-library access

Balavie requests camera or photo-library access only when the user chooses to take or select a meal photograph.

Balavie does not request location, contacts, SMS, call-log, or microphone access for meal analysis.

11. Optional donations

Balavie may provide an optional donation function processed through Stripe.

Balavie remains free to use. Donations do not unlock subscriptions, premium features, additional Gemini analyses, higher limits, additional storage, or digital goods.

Stripe receives only the information required to process the voluntary donation. Balavie does not send meal descriptions, meal photographs, nutrition results, health-related settings, Firebase history, or Gemini API keys to Stripe.

Balavie does not store complete payment-card information. Stripe may process and retain transaction information according to Stripe’s own privacy policy and legal obligations.

Gemini API charges are separate from any Balavie donation and are paid directly by the user to Google.

12. Service providers

Balavie uses or may use the following service providers:

  • Google Gemini API for user-requested meal analysis
  • Google Cloud Run for application and backend hosting
  • Firebase Authentication for user accounts
  • Firebase Firestore for synchronized meal records
  • Firebase Storage for private meal photographs
  • Stripe for optional donations
  • GitHub and GitHub Pages for source code, project information, support, and policy pages

13. Advertising and sale of information

Balavie does not sell or rent personal information.

Balavie does not use meal information, photographs, dietary settings, or Gemini API keys for advertising or commercial profiling.

Balavie does not intentionally integrate advertising networks, cross-site advertising trackers, or data brokers.

14. Technical and server logs

Balavie’s hosting providers may generate technical logs concerning requests, runtime errors, security events, and application performance.

Balavie does not intentionally log Gemini API keys, complete meal photographs, or Base64 image content.

Technical logs may be retained temporarily according to the relevant infrastructure provider’s retention settings.

15. Data retention

  • Meal records remain until deleted by the user or removed through account deletion.
  • Cloud meal photographs are retained for up to six months unless deleted earlier.
  • Firebase account information remains until the account is deleted.
  • Locally stored information remains until removed from the device.
  • Optional donation records may be retained by Stripe according to payment, fraud-prevention, accounting, security, or legal requirements.
  • Limited technical records may remain temporarily in infrastructure logs or backups until automatically overwritten or deleted.

16. Data deletion

Users may delete individual meals and associated photographs from their Balavie meal history.

Signed-in users may use Delete Account & Cloud Data in Balavie Settings to request permanent deletion of their:

  • Firebase Authentication account
  • Synchronized Firestore records
  • Stored Firebase Storage photographs
  • Local Balavie information
  • Saved Gemini API key
  • Age-confirmation and Gemini-consent records

Detailed deletion instructions are available on the ./data-deletion.html Account and Data Deletion page .

17. Security

Balavie uses HTTPS and service-provider security controls intended to protect information during transmission and storage.

Access to synchronized meal records and private photographs is restricted using Firebase Authentication and security rules.

No online service can guarantee absolute security. Users are responsible for protecting their device, Google account, authenticated Balavie session, and Gemini API key.

18. International processing

Google, Firebase, Stripe, GitHub, and related infrastructure providers may process information in countries outside the user’s country of residence.

Their processing is governed by their respective privacy policies, service terms, and applicable legal safeguards.

19. Nutrition and health information

Balavie provides approximate nutrition and lifestyle estimates for educational purposes only. Results may be inaccurate and are not medical advice, diagnosis, or treatment.

Users should independently verify important information, particularly information concerning allergies, intolerances, medical conditions, medication interactions, pregnancy, eating disorders, special diets, or nutrient deficiencies.

Balavie must not be relied upon to detect allergens or determine whether a meal is safe for a particular medical condition or dietary restriction.

Read the complete ./health-disclaimer.html Health Disclaimer .
