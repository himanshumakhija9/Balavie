Privacy Policy

Last updated: 9 August 2026

Balavie is a free and open-source meal and macro tracker providing approximate nutrition and lifestyle information for educational purposes.
Privacy summary
  • Balavie does not sell personal information.
  • Balavie does not contain advertising trackers.
  • Users provide and manage their own Gemini API key.
  • Information is sent to Gemini only when analysis is requested.
  • Meal photographs are stored locally on the user’s device.
  • Meal photographs are not synchronized to Balavie’s cloud database.
  • Users can delete meals, local photographs, and their account.
  • Balavie is intended only for users aged 18 and over.

1. About Balavie

Balavie helps users record meals, review estimated calories and nutrients, and receive AI-assisted nutrition and lifestyle estimates.

Open Balavie

View Balavie source code

2. Information processed

Account information

Firebase Authentication may process:

  • User identifier
  • Email address
  • Display name
  • Profile photograph URL, where provided
  • Authentication and account-security information

Meal information

Balavie may process:

  • Meal descriptions, dates, and times
  • Meal photographs selected by the user
  • Estimated calories and nutrients
  • Balance Scores
  • AI-generated nutrition and lifestyle estimates

Profile settings

Balavie may process:

  • Body weight
  • Dietary preferences
  • Activity level
  • Nutrition targets
  • Theme and interface preferences

3. Age and consent

Balavie is intended only for users aged 18 and over. Users must provide a one-time confirmation that they are at least 18 years old.

Balavie may store the confirmation status, date, and policy version. Balavie does not require or retain the user’s complete date of birth.

Balavie also stores a one-time record showing that the user accepted the Gemini data-processing notice.

4. Gemini meal analysis

Balavie operates in Bring Your Own Key mode. Users must create, provide, fund, protect, and manage their own Gemini API key.

When analysis is requested, Balavie may send Gemini:

  • The meal description
  • The selected meal photograph
  • Relevant dietary and activity settings
  • Relevant nutrition targets

Information is sent only after the user confirms being aged 18 or over, accepts the Gemini processing notice, provides a personal API key, and explicitly requests analysis.

Google controls Gemini API pricing, billing, quotas, availability, data practices, and service terms. Balavie cannot verify whether a user’s Gemini project is configured for a free or paid service tier.

5. Gemini API keys

A Gemini API key may be stored locally in the user’s browser or installed PWA.

Gemini API keys are not synchronized to Firebase or Firestore. Users can remove a saved key through Balavie Settings.

6. Meal photographs

Meal photographs are stored only on the user’s current device using IndexedDB.

Photographs are not synchronized to Firestore or any Balavie cloud database. Firestore meal records contain meal metadata and nutrition results but not photographs, Base64 image data, or photo URLs.

A local photograph remains on the device until:

  • The associated meal is deleted
  • The Balavie account and local application data are deleted
  • The browser or installed application storage is cleared
  • The application is removed and its local data is deleted

Local photographs may not be available on another device, even when the user signs in with the same account.

Balavie does not automatically publish, upload, or share photographs. Sharing is initiated manually by the user.

7. Local and cloud storage

Balavie may store locally:

  • Meal photographs in IndexedDB
  • Local meal-history information
  • Dietary, activity, and interface settings
  • Analysis counters
  • The user’s Gemini API key
  • Age-confirmation and consent records
  • Firebase Authentication state

Signed-in users may synchronize meal descriptions, nutrition estimates, Balance Scores, recommendations, and dates through Firebase Firestore.

Gemini API keys and meal photographs are not synchronized.

8. Device permissions

Camera or photo-library access is requested only when the user chooses to take or select a meal photograph.

Balavie does not require location, contacts, SMS, call-log, or microphone access for meal analysis.

9. Optional donations

Balavie may offer optional donations processed by Stripe. Donations do not unlock features, subscriptions, higher limits, additional analyses, or additional storage.

Balavie does not send meal information, photographs, nutrition results, dietary settings, Firebase history, or Gemini API keys to Stripe.

Balavie does not store complete payment-card information. Gemini API charges are separate and are paid directly by the user to Google.

10. Service providers

  • Google Gemini API for user-requested meal analysis
  • Google Cloud Run for application and backend hosting
  • Firebase Authentication for user accounts
  • Firebase Firestore for synchronized meal records
  • Stripe for optional donations
  • GitHub and GitHub Pages for source code and policy pages

11. Advertising and information sales

Balavie does not sell or rent personal information and does not use meal information, photographs, dietary settings, or API keys for advertising.

12. Technical logs

Hosting providers may generate technical logs concerning requests, runtime errors, security events, and application performance.

Balavie does not intentionally log Gemini API keys, complete meal photographs, or Base64 image content.

13. Data retention and deletion

  • Cloud meal records remain until deleted by the user.
  • Local photographs remain until deleted from the user’s device.
  • Account information remains until account deletion.
  • Stripe may retain donation records under its own requirements.
  • Technical logs may remain temporarily in provider systems.

Users may delete individual meals and associated local photographs or use Delete Account & Cloud Data in Balavie Settings.

Read the Account and Data Deletion instructions

14. Security

Balavie uses HTTPS, Firebase Authentication, and Firebase security rules. No online system can guarantee absolute security.

Users are responsible for protecting their device, Google account, Balavie session, and Gemini API key.

15. Health information

Balavie provides approximate nutrition information for educational purposes only. Results may be inaccurate and are not medical advice, diagnosis, or treatment.

Read the complete Health Disclaimer
