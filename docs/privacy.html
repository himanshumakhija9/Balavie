Privacy Policy

Last updated: 9 August 2026

Balavie is a free and open-source meal and macro tracker providing approximate nutrition information for educational purposes.
Privacy summary
  • Balavie does not sell personal information.
  • Balavie does not contain advertising trackers.
  • Users provide and manage their own Gemini API key.
  • Information is sent to Gemini only when analysis is requested.
  • Saved meal photographs are private by default.
  • Users can delete meals, photographs and their account.
  • Balavie is intended only for users aged 18 and over.

1. About Balavie

Balavie helps users record meals, review estimated calories and nutrients and receive AI-assisted nutrition and lifestyle estimates.

2. Information processed

Account information

Firebase Authentication may process:

  • User identifier
  • Email address
  • Display name
  • Profile photograph URL, where provided
  • Authentication and account-security information

Meal information

  • Meal descriptions, dates and times
  • Meal photographs
  • Estimated calories and nutrients
  • Balance Scores
  • AI-generated nutrition and lifestyle estimates

Profile settings

  • Body weight
  • Dietary preferences
  • Activity level
  • Nutrition targets
  • Theme and interface preferences

3. Age and consent

Balavie is intended only for users aged 18 and over. Users provide a one-time 18+ confirmation during onboarding.

Balavie may store the confirmation status, date and policy version. Balavie does not require or retain the user’s complete date of birth.

Balavie also stores a one-time record of consent to send user-requested meal information to Google’s Gemini API.

4. Gemini meal analysis

Balavie operates in Bring Your Own Key mode. Users must create, provide, fund, protect and manage their own Gemini API key.

When analysis is requested, Balavie may send Gemini:

  • The meal description
  • The selected meal photograph
  • Relevant dietary and activity settings
  • Relevant nutrition targets

Information is sent only after the user confirms being 18 or over, accepts the processing notice, provides an API key and explicitly requests analysis.

Google controls Gemini pricing, billing, quotas, availability, data practices and service terms. Balavie cannot verify whether a project uses a free or paid Gemini service tier.

5. Gemini API keys

A Gemini API key may be stored locally in the user’s browser or installed PWA. Gemini keys are not synchronized to Firebase or Firestore.

Users can remove a saved API key through Balavie Settings.

6. Meal photographs

Meal photographs may be used for Gemini analysis and saved privately with meal history.

Cloud photographs are stored in Firebase Storage. Firestore stores only the required photograph reference and metadata rather than Base64 image data.

Photographs are private by default and are not automatically published or shared.

Cloud photographs are retained for up to six months unless the user deletes the photograph, meal or account earlier.

7. Local and cloud storage

Balavie may store locally:

  • Meal history and retained photographs
  • Dietary, activity and interface settings
  • Analysis counters
  • The user’s Gemini API key
  • Age-confirmation and consent records
  • Firebase Authentication state

Signed-in users may synchronize meal records through Firebase Firestore. Gemini API keys are not synchronized.

8. Device permissions

Camera or photo-library access is requested only when the user chooses to take or select a meal photograph.

Balavie does not require location, contacts, SMS, call-log or microphone access for meal analysis.

9. Optional donations

Balavie may offer optional donations processed by Stripe. Donations do not unlock features, subscriptions, higher limits or additional storage.

Balavie does not send meal information, photographs, nutrition results, dietary settings, Firebase history or Gemini keys to Stripe.

Balavie does not store complete payment-card information. Gemini API charges are separate and are paid directly to Google.

10. Service providers

  • Google Gemini API for meal analysis
  • Google Cloud Run for hosting
  • Firebase Authentication for accounts
  • Firebase Firestore for synchronized meal records
  • Firebase Storage for private photographs
  • Stripe for optional donations
  • GitHub and GitHub Pages for source code and policy pages

11. Advertising and information sales

Balavie does not sell or rent personal information and does not use meal information, photographs, dietary settings or API keys for advertising.

12. Data retention and deletion

  • Meal records remain until deleted by the user.
  • Cloud photographs are retained for up to six months.
  • Account information remains until account deletion.
  • Local information remains until removed from the device.
  • Stripe may retain donation records under its own requirements.

Users may delete individual meals and photographs or use Delete Account & Cloud Data in Balavie Settings.

13. Security

Balavie uses HTTPS, Firebase Authentication and Firebase security rules. No online system can guarantee absolute security.

Users are responsible for protecting their device, Google account, Balavie session and Gemini API key.

14. Health information

Balavie provides approximate nutrition information for educational purposes only. Results may be inaccurate and are not medical advice, diagnosis or treatment.

15. Changes and contact

This Privacy Policy may be updated when Balavie’s functionality, service providers or data practices change.
