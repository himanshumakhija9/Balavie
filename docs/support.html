Support

Last updated: 9 August 2026

Balavie is a free and open-source learning project. Support is provided on a reasonable-effort basis, and response times are not guaranteed.

Contact Balavie Support

Contact Balavie for general questions, technical issues, privacy concerns, security reports or account-deletion assistance.

Report a technical issue

Include the following non-sensitive details:

  • A brief description of the issue
  • The steps that caused the issue
  • The device and browser being used
  • Whether Balavie was installed as a PWA
  • Any non-sensitive error message displayed

Account and data deletion

Signed-in users can delete their account through Balavie Settings by selecting Delete Account & Cloud Data.

If the in-app option is unavailable, submit a deletion request by email.

Gemini API key assistance

Balavie uses a Gemini API key supplied and managed by the user. Google controls API keys, billing, pricing, quotas, projects and availability.

Balavie support cannot:

  • Create or recover a Gemini API key
  • Access a user’s Google Cloud project
  • Configure billing, budgets or quotas
  • Verify whether a project uses a free or paid service tier
  • Refund charges made by Google

Optional donations

Balavie is free and open source. Optional donations do not unlock features, subscriptions, additional analyses, additional storage or premium services.

For a donation issue, provide only the approximate transaction date and the email address used for the transaction.

Security reports

Do not publish sensitive security information in a public GitHub issue. Submit security concerns privately by email.

Never send sensitive information

Never send a Gemini API key, password, authentication code, payment-card information, Firebase credential or private meal photograph by email or through a public GitHub issue.
