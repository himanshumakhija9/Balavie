# Balavie

Balavie is an open-source, AI-powered meal and macro tracker that helps users understand their nutrition and build healthier habits through personalized insights.

- **Live App**: [https://balavie.ai.studio/](https://balavie.ai.studio/)
- **GitHub Repository**: [https://github.com/himanshumakhija9/Balavie](https://github.com/himanshumakhija9/Balavie)
- **GitHub Pages**: [https://himanshumakhija9.github.io/Balavie/](https://himanshumakhija9.github.io/Balavie/)

## Features

- **Automated Meal Analysis**: Powered by Gemini AI for instant macro breakdown.
- **Private Cloud Meal Storage**: Save meal photos privately in Firebase Storage, automatically deleted after 6 months.
- **Athletic Balance Score**: Real-time calculation of your daily nutrient ratios.
- **Bring Your Own Key (BYOK)**: Secure server-side Gemini integration.
- **PWA Ready**: Installable app with offline capabilities.
